# Find the Modak Design System

An extracted, reusable design system for the Find the Modak maze game.

## Source

This system was distilled from the existing root-level `index.html`,
`style.css`, and `script.js`. It captures the current visual language without
changing the game itself.

## Files

- `tokens.css` — color, typography, spacing, radius, shadow, and motion tokens.
- `components.css` — reusable buttons, panels, pills, progress, stats, callouts,
  swatches, and responsive layout primitives.
- `showcase.js` — the small interactions used by the gallery.
- `index.html` — a visual reference page for the system.
- `docs/AGENTS.md` — instructions for using this system in future artifacts.

## Direction

The system combines a deep plum night canvas with warm saffron/gold emphasis,
rose alerts, cream typography, soft glows, and friendly rounded surfaces. It
should feel like a glowing festival pandal translated into a focused game UI:
welcoming, legible, and lightly playful.
